## 尺度结论与产物

同一 390×568 CSS px 视口、2× 相机中对照 24px / 约32px 可见人物及各自配套家具后，选择 **24px 可见站姿，32×32 统一帧**。新沙发 80×48、两块26px坐垫；人物肩/臂轮廓14–17px；净门洞22×32；杯身4×5，对应手部2×3。比例图检查了门、站/坐、肩宽/坐垫和手/杯，未通过单独缩放人物解决旧比例问题。

- **56 张人物帧**：每位四方向待机、四方向×四帧步态、四方向坐姿、左右依靠各两帧。所有方向共用脚锚 `(16,29)`；站、坐、步态、依靠同向头部像素一致。海边与室内复用新标准资源。
- **42 张客厅帧**：日/夜家具及装饰；电视机壳与27×20屏幕、窗框与39×49窗外、四帧28×28火焰、沙发前后层分开。没有把示意双人层放入运行资产。
- **两个正式格式图集**与全部单件：人物1024×80、客厅1024×368；完整帧、不trim、不旋转，2px留边及1px extrusion。
- **纯角色数据**：`characters-pixels.json` 可承接现有 makeTexture 与 DOM 头像。图集/PNG/字符网格的数据一致。
- **接口与源文件**：`manifest.json` 包含资源key、尺寸、可见bbox、origin/脚锚、帧序、减少动态帧、绘制层序、坐席/起身/互动/footprint提案。可编辑源在 `art-02/source/`。
- **静态视觉证据**：同视口尺度对照、人物全帧、人物/门/家具/杯子比例、白天/夜晚、海边站/坐/靠、320/390px取景。见 [完整索引](../../../designs/art-02/README.md)。

## 实际看图与修正

使用 view_image 查看了尺度对照、完整帧表、人物姿态、日夜室内、比例表、海边姿态和小屏取景。没有控制应用浏览器。

先前候选人物与宽沙发改为成套重绘的24px标准；角色头部共用，白熊四方向的脚底补齐到精确24px可见站高。修正了对照图旧门/新门的呈现，保留同一地面基准。客厅补充紧贴炉台/电视脚部的阴影，以及保留木纹板缝的局部窗光。手机操作留位采用更深青绿底配浅字，字号没有随整屋缩小。运行资源保留独立动态内容和透明洞，不含预览人物。
