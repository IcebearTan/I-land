## 阅读方案

列表显示日期、署名、摘要与页数；七夕信使用局部淡紫信封与火漆，保留拆信动作。
阅读时优先显示原笔迹：大阅读区、固定页码导航与上下页、原比例纵向滚动、放大后横向平移。
信纸不裁切、不像素化、不 OCR 改写；装饰只在外层，避免覆盖文字。
手机面板限定在可用宽度内，图片失败可单页重试，减少动态偏好沿用项目约定。

## 工具与维护

新增 `backend/app/import_letters.py`：只解析字面量，不执行任意 JS；默认预览，显式 --apply 才写入。
采用来源哈希、逐页上传日志与工具锁；通过 API 精确比对已建信防止本工具重跑重复。
这不代替未来公共寄信 API 的数据库级并发幂等；日志绑定账号和 URL，不能换目标或丢日志后任意重导。
维护工具的附件引用扫描新增对 Letter.pages 受保护附件 URL 的识别，避免已迁入信纸被误列为孤立候选。
这不实现 MAIL-01 的新附件字段、公共写信 API 校验、软删除或未读状态。
