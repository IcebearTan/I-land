# I-land「星光阁楼书房 · 双人自习室」设计与架构方案

> 日期：2026-11-28 | 状态：已实现并上线
> 目标：在 I-land 像素小岛内打造兼具「高情绪价值像素陪伴」与「高频实用番茄钟 + 不切微信专属轻聊」的双人自习室，并通过渲染节流与单通道复用保证手机长时间挂机省电流畅。

---

## 1. 空间定位与世界外观：为什么是「小屋二楼 · 星光阁楼书房」

相比在 `640×480` 的精致海岛上硬塞一栋略显公事公办的“学校/自习大楼”，将自习室设计为**温馨小屋二楼的「星光阁楼书房」（`StudyScene`）**能同时拉满浪漫叙事与空间秩序：

1. **主岛屋外动态联动（打破小岛静态感）**：
   - 在主岛小屋（`cottage-v3`）斜屋顶增绘一扇精致的**像素老虎窗（阁楼天窗）**。
   - **实时陪伴感知**：平时为安静木窗；只要任意一方正在书房专注，主岛屋顶天窗便透出 `#ffd98a` 琥珀暖光，走近小屋门口也会浮现温和提示（如 `yearning 正在阁楼看书`）。
2. **一楼松弛、二楼专注的自然分区**：
   - 一楼客厅（`InteriorScene`）保留壁炉、沙发、电视与记忆挂历的休闲定位；
   - 二楼阁楼（`StudyScene`）采用类似海边（`SeasideScene`）的**免走位定焦像素取景构图**——进屋即并排落座长书桌前，省去每次学习还要摇杆绕路找椅子的摩擦。

## 2. 三级入口设计（兼顾世界仪式感与 1 秒直达）

为避免日常高频自习“每次都要先走地图进门”，提供三条互通路径：

1. **登岛准备页直达（`DockOverlay` 快车道 · 最高频）**：
   - 在登岛准备卡片 `乘船登岛` 主按钮旁新增次级木牌按钮 **「直达书房」**（扩展 `NavigationScene` 支持 `login -> study`）。
   - **在线召唤感**：通过轻量状态接口，若对方正在书房，登岛副标题直接显示 **「yearning 正在阁楼自习 · 专注剩余 16:40」**，按钮自动切换为高亮 **「去陪她自习」**，一点即达。
2. **岛上 HUD 快捷槽（`Hud` 工具栏）**：
   - 主岛右上角像素槽位栏新增 **「阁楼书房」** 图标槽；当对方在书房时槽位角标亮起暖黄像素光点，在岛上任何角落均可一键上楼。
3. **世界内空间入口（`InteriorScene` 客厅木梯）**：
   - 在一楼客厅东北侧墙边增设 **「上阁楼木梯」** 交互点，走近浮现气泡 `上阁楼 · 双人自习室`，支持 `island <-> interior <-> study` 完整空间漫游，书房左上角亦可一键 `回到小岛` 或 `下楼去客厅`。

## 3. 阁楼内饰、活人感微状态机与响应式构图

### 3.1 16-bit 阁楼内饰三层景深
```text
┌──────────────────────────────────────────────────────────────┐
│  [左：满墙像素橡木书架/地球仪]   [中：宽幅斜顶海景天窗]   [右：挂墙番茄钟/暖壁灯] │
│                         （窗外实时映射晨/昼/昏/夜 + 远眺灯塔真实色光）        │
│         ┌──────────────────────────────────────────┐         │
│         │  [绿罩黄铜台灯]   [小花瓶]   [绿罩黄铜台灯]  │         │
│         │   🐻 小熊左席                 👧 她右席    │  [窗台打盹小猫]
│         │  (小熊杯+盆栽)               (玫瑰茶+书签)  │         │
│         └──────────────────────────────────────────┘         │
└──────────────────────────────────────────────────────────────┘
```
- **真实世界联动**：斜顶大窗外不仅随现实时间平滑切换黎明、晴海、晚霞与星夜，还会在远景海岬画出微缩的**灯语信号塔**，实时渲染你们当前设定的真实灯语颜色（联动 `/api/lighthouse`）。
- **角色与桌面「微状态机」（告别死板贴图）**：
  - **空闲入座（`idle`）**：台灯微暗，角色安静坐着偶尔眨眼/轻晃。
  - **专注中（`focusing`）**：该座位黄铜台灯点亮暖金光晕，桌面摊开像素书本，角色以极慢节奏（每 `2.5–4s`）触发翻页或低头执笔微动作，座位上方浮现小木牌展示当前目标（如 `看文献`）。
  - **休息中（`resting`）**：书本合上，桌角马克杯升起 3 帧像素热气，角色切换为捧杯小憩/望向窗外海面。
  - **双人同席彩蛋（`together`）**：两人同时在场时，书桌中央空花瓶自动插上一支小花，窗台软垫上多出一只随呼吸起伏打盹的小橘猫。

### 3.2 桌面与移动端响应式布局（彻底解决软键盘挤压）
- **桌面 / 平板横屏（`> 820px`）**：左右黄金分栏——左侧 `54%` 为阁楼像素画卷，右侧 `46%` 为雕花橡木书房面板（上半区：双人番茄钟与状态卡；下半区：书房专属聊天室）。
- **手机竖屏（`≤ 820px`）**：上下三段式——顶部 `32%` 阁楼全景取景窗 + 中部紧凑番茄钟控制条 + 底部羊皮纸聊天流与输入栏。
- **手机输入法智能避让（`visualViewport` 监听）**：当手机软键盘弹起打字时，顶部像素画布自动平滑折叠为 `48px` 的「双人像素小头像 + 实时倒计时」窄横条，把可视高度全部让给聊天记录与输入框，手感贴近原生聊天软件。

## 4. 核心功能与情绪交互细节

### 4.1 双模番茄钟（自由独立 × 一键同频）
- **多档位与正向计时**：内置 `25/5`（经典番茄）、`45/10`（深度自习）、`60/10`（长时沉浸）、自定义（`10–120` 分钟）及 **「正向自由计时」**（不设上限，记录已专注时长）；开钟前可填一句 `≤ 24` 字的本轮小目标（保留最近 3 个快捷历史词条一键复选）。
- **独立与同频无缝切换**：
  - 默认各自独立控制自己的番茄钟，同时实时看到对方的剩余时间与正在做的事；
  - 当对方正在专注或休息时，面板浮现 **「跟随她的节奏」** 按钮，一键对齐对方的阶段与 `ends_at_utc_ms`，实现两人同一秒听到柔和木琴提示音、同一秒进入休息闲聊。
- **严守小岛无惩罚铁律**：中途提前结束或断线离开绝不扣分、不留失败记录；专注满 `≥ 5 分钟` 即温柔记入「今日共学足迹」。

### 4.2 替代切去微信的「书房轻聊」与心流免打扰
- **完整轻聊能力**：
  - 支持多行文本（`Enter` 发送 / 移动端独立发送钮）与**图片/题目截图发送**（100% 复用现有 `POST /api/uploads` WebP 三档转码、EXIF 去敏与 `mark_attachments_linked` 引用保护，点击缩略图可原位放大看题）。
  - 聊天记录落库 SQLite，支持向上滚动按 `before_id` 翻阅历史、断线重连按 `after_id` 自动补齐漏收消息。
- **专注期「免打扰柔光模式」**：
  - 本人处于 `focusing` 阶段时，新消息不弹响铃、不抖动画面，仅在聊天栏标题旁亮起琥珀柔光点与单行轻预览（手机端支持一键把聊天区折成单行专注条，有事点开仍可随时回）；
  - 倒计时结束进入 `resting` 休息阶段时，聊天区自动舒展高亮，提示 `休息 5 分钟，喝口水聊两句吧`。
- **零打字「桌边轻互动」（专注中不打扰也能传情）**：
  - 提供 4 个 15 秒冷却的像素小动作按钮：**「递杯热茶」**、**「摸摸头加油」**、**「轻轻戳一下」**、**「送朵小花」**。
  - 不污染持久聊天记录，直接经房间广播在画布上触发茶杯冒暖气 / 头顶飘像素爱心，并在状态条浮现 4 秒温柔小字（如 `小熊悄悄给你添了一杯热茶`）。

### 4.3 书房白噪音快捷混音与常亮辅助
- **一键白噪音切换**：复用 `AudioScene` 已加载音轨，在书房内直接提供 `纯白噪音（壁炉+海浪/虫鸣，关旋律）`、`轻音乐伴读`、`静音` 三态切换，无需点开全局设置弹窗。
- **手机常亮开关（Wake Lock）**：提供可选「屏幕常亮」按钮（调用原生 `navigator.wakeLock`，切后台自动释放），方便手机立在书桌角落当桌面钟。

## 5. 性能与电量保障架构（挂机 2 小时不发烫的关键）

针对 Phaser 画布在移动端长时间常驻易耗电的痛点，采取四层硬核节流：

1. **零物理引擎 + 脏帧节拍渲染（功耗直降 85%+）**：
   - `StudyScene` **不挂载 Arcade Physics**；木墙、书架、长桌等静态层在进场时一次合成为单张缓存纹理（严守 `DESIGN.md` 纹理只 refresh 不 remove 铁律）。
   - 场景内动画全部采用 `600ms–1200ms` 步进的像素节拍器：无指针操作且无补间动画时，主动跳过空帧更新；页面处于后台（`document.hidden`）时完全暂停场景步进。
   - 番茄倒计时完全基于服务端权威时间戳 `ends_at_utc_ms - Date.now()` 推算，手机锁屏/切后台再回来 **0 秒误差**。
2. **高频跳字与画布彻底隔离**：
   - 每秒变化的 `mm:ss` 倒计时封装在独立的纯文本子组件 `<StudyTimerReadout />` 中，**每秒只更新一个 DOM 文本节点**，绝不触发 `StudyChatList` 或 Phaser 画布重绘。
3. **单条 WebSocket 复用（严守 2C4G 云主机内存预算）**：
   - 扩展 `backend/app/room_runtime.py`，将合法房间扩充为 `("seaside", "interior", "study")`，共用同一个 `RoomCoordinator` 锁与租约机制。
   - 进书房只建立 **1 条** WS 连接，统一推送房间快照（在线成员、各自番茄钟锚点、轻互动事件、最新消息游标 `latest_message_id`），不引入任何额外中间件或轮询风暴。
4. **100% 严守 `iland-ui-style` 像素视觉与清晰度红线**：
   - 全局锁定 `ArkPixel` + `font-weight: 400; font-synthesis: none;` + `border-radius: 0` + 橡木滚动条；
   - 聊天正文固定采用最锐利的 **`16px` 对齐字号 + `1.6` 行高**，本人消息用暖琥珀笺底，对方消息用奶油羊皮纸底，长时间阅读清晰不糊。

## 6. 数据模型、Donut 契约与模块化实施拆分

### 6.1 新增 SQLite 数据表（`backend/app/models.py`）
- `StudyTimerState`（按 `account: "bear" | "her"` 主键持久化，共 2 行）：`phase`（`idle | focusing | resting | stopwatch`）、`focus_minutes`、`break_minutes`、`started_at_ms`、`ends_at_ms`、`goal_text`、`synced_with`、`version`——确保刷新页面或短暂断网重连后，正在跑的番茄钟丝毫不乱。
- `StudySession`（专注完成历史）：`id`、`account`、`goal_text`、`duration_minutes`、`together`（是否双人同场完成）、`started_at`、`completed_at`、`date`（`YYYY-MM-DD`）。
- `StudyMessage`（书房专属轻聊）：`id`、`sender`（`bear | her`）、`body`（`≤ 1000` 字）、`attachment_id`（可选，写入时调用 `mark_attachments_linked` 并纳入 `attachments.py` 引用扫描防误删）、`client_id`（幂等防重发）、`created_at`。

### 6.2 同步履行 `AGENTS.md` 第 7 条 Donut 三步契约
1. **后端 REST**：新增 `backend/app/routers/study.py`（`/api/study/overview`、`/api/study/timer`、`/api/study/sessions`、`/api/study/messages`、`/api/study/nudge`），统一复用 `Depends(get_current_user)`。
2. **聚合摘要**：在 `GET /api/agent/digest` 中新增 `study` 字段（当前谁在书房、是否专注中、今日/近 7 天双方专注时长与共学番茄数；**私聊消息正文不进普通 digest**，兼顾助手知情与聊天私密感）。
3. **CLI 与 Skill**：在 `iland_cli.py` 增加 `study status`、`study stats` 子命令并同步更新 `SKILL.md`。

### 6.3 分阶段模块化落地计划（严格遵守单文件 `≤ 250` 行）
- **Phase 1（后端模型、房间扩展与测试）**：新增 3 张表、`room_runtime.py` 接入 `"study"` 房间与主岛书房亮灯摘要、`routers/study.py` 与 `attachments.py` 引用扫描、pytest 定向测试通过后 `git commit`。
- **Phase 2（阁楼像素美术与低功耗 `StudyScene`）**：拆分 `game/art/study.ts`（阁楼书架/天窗/双人书桌/台灯/小猫像素绘制）+ `game/scenes/StudyScene.ts`（微状态机与低功耗节拍）+ 主岛屋顶天窗与客厅木梯入口 + `NavigationScene` 直达支持，构建通过后 `git commit`。
- **Phase 3（React 雕花橡木控制台与防遮挡轻聊 UI）**：模块化拆分为 `study/StudyWorkspace.tsx`（响应式壳层与键盘避让）、`study/StudyPomodoroBar.tsx`（双模番茄钟与 `<StudyTimerReadout />`）、`study/StudyChatPanel.tsx`（免打扰轻聊 + 截图预览 + 桌边轻互动）及 `DockOverlay`/`Hud` 快捷入口，跑静态像素合规扫描 + 前端构建后 `git commit`。
- **Phase 4（Donut 契约接入、云端部署与线上验收）**：补齐 `/api/agent/digest` 与 `iland_cli.py`、执行云端增量发布、清理全部验收测试数据。
