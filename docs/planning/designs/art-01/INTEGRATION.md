# ART-01 → ART-02 / ART-03 接入清单

本文件是后续接入提案。当前没有改 `frontend/`、没有导入 Phaser、没有生成可直接加载的 Tiled 地图。坐标属于 **320×240 样板**，并非现有 `HOME_LAYOUT` 的新值。

## 分层

每种时段均有 12 张 320×240 全画布透明层，按文件名前缀叠加可逐像素重建最终图。原始 PNG 与 SVG 图层组同名。

| 层 | Tiled / 图集接入方向 |
| --- | --- |
| 00 shell-floor | tile 层拆成墙、踢脚、地板；16px 网格，原图纹理方向不变 |
| 01 local-floor-light | 灯光遮罩/调色层，保留板缝；可降级为静态日夜版本 |
| 02 contact-shadows | 家具接地阴影层，不生成碰撞 |
| 03 window | 窗框/帘固定；窗外景色独立更新；不能 tint 两次 |
| 04 fireplace | 炉体静态资产；炉台陈列与炉体后续拆分 |
| 05 tv-cabinet | 柜/机壳静态资产；屏幕遮罩单独裁出，接现有三个原创频道 |
| 06 fire | 独立 40×34 透明关键帧；未来四帧统一画布、锚和亮度范围 |
| 07 rug | 地面装饰，无阻挡，无交互 |
| 08 sofa-base | 沙发底座与坐垫，在坐着的人物之前画 |
| 09 scale-actors-NOT-live | **仅样板比例层，接入时丢弃**；真人来源仍由当前身份/经确认的房间成员决定 |
| 10 sofa-foreground | 近侧靠背 + 披毯；在坐着的人物之后画，不能整张挡住站立人物 |
| 11 details | 装饰拆单件并按脚底 Y 排序；不会自动变成新玩法 |

全画布层适合评审与对照。正式运行不能把整屋当一张背景图绕过深度排序；按单件脚底 Y 排序，沙发使用局部前后遮挡规则。窗外、炉火、电视内容和静态装饰应分开。

## 草稿图集

`assets/atlas-draft.png` + `.json` 包含 17 个透明原图，保留完整帧，不旋转、不 trim；每边留 2px，内层 1px extrusion。角色帧一致为 `32×40`，沙发前后层一致为 `128×65`。`sofa-complete` 仅用于预览，运行时不能同时绘制它和前后层。

当前石壁/柜/窗已经有独立原图；装饰仍集中在 `11-details`，正式制作应拆为单件图集条目。原图日色是基础材质；夜间整屋层已带样板受光，正式 shader/tint 接入应选择基础材质或预烘焙版本之一，避免叠加变暗。

## 后续验收顺序

1. ART-02 在相同相机视口比较现有 16px 与候选约 32px 人物，锁定头身、方向帧、脚锚，再扩动作；候选不能直接混进旧主岛。
2. ART-03 建立 16px tile set 和 Tiled object layers：`collision`、`interactables`、`seats`、`stand_points`、`light_sources`、`occluders`；先映射现有入口和安全返回点。
3. 拆出 CRT 屏幕与窗外、炉体陈列，按静态图集 / 动态内容分开维护；炉火动画所有帧检查相同画布与透明边。
4. 在隔离验收服务验证走近壁炉、电视、双侧入座与起身、沙发绕行、走后侧遮挡、返回主岛；保留原 EventBus / API 边界。
5. 320/390px 使用固定 2× 像素并允许相机跟随/平移。静态中心裁切会隐藏左炉侧和右窗侧，本包图中已呈现这个限制；禁止把整屋降到 1× 冒充小屏完成。
6. DOM 操作目标至少 44px，文字对比沿用核心深浅色，不让提示盖人物或炉口；减少动态选择静态火焰/电视关键帧。
7. HOME-02 只有真实房间确认的座位成员可画出两人；当前示意人物层必须删除。单人和断线状态也要有完整画面。
8. 按实际改动跑构建/必要测试、桌面/模拟窄屏检查，并单独记录 iOS/Android 真机与线上状态。
