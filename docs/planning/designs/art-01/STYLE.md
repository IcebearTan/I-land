# ART-01 风格表

目标是原创像素生活场景，参考《星露谷物语》的材质区分与俯视体积；不复制其素材。基于 DESIGN.md 核心色，新增材质色只存在本包，等待后续正式资产阶段采纳。

| 项目 | 本样板规格 |
| --- | --- |
| 场景 / tile | 320×240 逻辑像素，16×16 tile；轴向 3/4 俯视，墙脚保持水平 |
| 笔触 / 缩放 | 1px 为最小笔触；2–4px 色簇构造轮廓；原图无抗锯齿；2×、3×、4×最近邻 |
| 角色画布 | 32×40，站姿可见高度 31px、坐姿 27px；脚底锚 `(16,36)`；画布不等于碰撞 |
| 头部 | 白熊 18×13、岛民 17×14 可见包围盒；同向站坐直接复用同一头部像素 |
| 沙发 | 128×65 画布；两块约 40px 坐垫，厚扶手，单独近侧靠背/毛毯遮挡层 |
| 中文 / 图注 | 普通中文字体，浅底 `#4a3b55`、深底 `#f5eee2`；不嵌入像素资产 |
| 动画 | 本包全部静态；火焰仅关键帧。将来减少动态模式使用这类静态关键帧 |

核心色沿用：奶油 `#fdf6e9`、浅字 `#f5eee2`、深字 `#4a3b55`、沙 `#f0d9a8`、暖光 `#ffd98a`、海 `#3f6f9e/#7fb6d9`、草 `#5a944a/#7cb860`。角色青绿 `#3f887f/#62b2a2`、白毛 `#fffaf2/#e6e8e3`、轮廓 `#8c999a`、黑发 `#20222e/#393946`、黑裤 `#242333` 保持现有身份语言。

| 材质 | 暗 → 亮派生色 | 识别方式 |
| --- | --- | --- |
| 橡木 | `#554451 #765346 #976b4f #b88b60 #d2ac78 #e5c897` | 错缝、顺纹长线、少量节疤与钉孔；顶面亮、竖面中、落地暗 |
| 暖石 | `#65545c #8e7d77 #afa08b #cfbea0 #e3d4b9 #f5e7cc` | 不等长石块、拱形放射石、缺口聚集在边缘，炉口有厚度 |
| 陶红布 | `#694655 #8c5158 #ad645d #c97e69 #df9d7d #edb497` | 圆转扶手、凹陷坐垫、压线和边缘折痕；大面保持安静 |
| 青绿毯 | `#294f59 #326860 #3f887f #62b2a2 #a2cdb5` | 先表现折面方向，再画窄织纹和流苏；右扶手处折转 |
| 白毛 | `#8c999a #c5d1ce #e6e8e3 #fffaf2` | 圆耳、长身体、克制面部，无围巾；毛色不等同墙面奶油 |

少量结构辅助色（地板邻板、窗外、炉膛和肤色）在绘制源中明示；`source/palette.json` 为主要色组，不声称导出画面只有 32 色。夜间色来自可复算的受光映射，正式 GPU 灯光接入前仍需按设备核对。

白天由右侧窗口提供冷蓝环境与斜落地投影；家具统一用左上亮边表达体积，落地阴影紧贴脚部。炉火仍只影响炉口和近处板材，不给整个房间加橙色滤镜。日光投影重新映射木板原像素，保留接缝与木纹。

夜晚采用冷靛灰环境，炉口 `(77,102)` 有有限范围的暖反射；窗光 `(261,96)` 维持冷色。暖反射被量化成像素色阶，没有高斯模糊、半透明边或全屋橙色罩层。电视保持同一海景关键帧；将来可加微弱独立蓝光，不能盖过人物与炉火。

避免平均撒噪点、全屏棋盘抖动、统一黑粗描边、整屋发橙、用阴影代替家具侧面、坐下整体缩放人物、把猫耳画到岛民头上，以及把胸前罗小黑图案画到衣服背面。当前小屏样板保留真实 2×像素，不能靠缩小整屋来隐藏细节。
