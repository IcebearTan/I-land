# COCOA-03 素材接入说明

机器接口是 `frontend/public/art-v2/cocoa/manifest.json`，版本 `cocoa-art-1.0.0`。独立atlas key为`cocoa-art`；不覆盖现有`art-v2-characters`和`art-v2-home`。

## 尺寸与局部坐标

| 对象 | 尺寸 / 原点 | 局部定位 |

| 人物所有动作层 | 32×32，origin `(0.5,0.90625)` | 脚锚 `(16,29)`，sprite scale 1 |
| 料理台 base/front | 各72×52，origin `(0,0)` | 局部左上角 `(0,0)` |
| 占地提案 | `(4,35,64,14)` | 需要整合者实测；不是已验碰撞 |
| 控温工位 | 脚点 `(18,32)`，朝down | 台后站位，伸手到左侧旋钮 |
| 搅拌工位 | 脚点 `(50,32)`，朝down | 台后站位，勺尖进入锅口 |
| 安全起身候选 | `(18,62)/(50,62)` | 退出活动后仍需路径检查 |
| 互动点候选 | `(36,62)` | 台前中央 |

不提供绝对料理台位置，也不重排客厅。需给台后两个工位预留可达空间，避开门、沙发起身区和原家具；保留现有入口坐标。只有服务端确认的工位成员可画成操作状态，不能补画远端走过来的假轨迹。

## 工作动作层序

1. 地面与环境。
2. 工位角色的`body`，以统一脚锚定位。
3. `counter-base`、`burner`、`pot`、`knob`、`counter-front`。
4. 同一动作的`hands`，与body使用完全相同位置/尺寸/origin。
5. 蒸汽；它向右上侧飘，避免覆盖搅拌者脸部。

`pose`是body+hands合成的完整32×32姿势，可用于没有桌面遮挡的预览/普通动作；工位应使用分层版，以免下身浮在桌面上。身体与手层是同帧号，不能错配。

`{bear|her}-heat-down-{0..2}`为控温；`stir-down-{0..3}`为搅拌。循环仅为视觉反馈，不自行增加温度/进度。动画建议4/5fps，暂停、掉线与状态切换由服务端确认结果控制。旋钮帧可随控温动作选择；热盘档位只表达当前设置，不强行映射未定义的协议数值。

## 杯子与双人动作

- `{identity}-hold-{down|up|right|left}-0`：四方向持杯。
- `{identity}-offer-{right|left}-{0..2}`：递出。
- `{identity}-receive-{right|left}-{0..2}`：空手伸手接杯。
- `{identity}-clink-{right|left}-{0..3}`：举杯、接触停留、收回。第1/2帧刻意保持接触，不是缺帧。

每个动作给出`hand`和可选`cup.grip/flipX`。杯帧选择`cup-{cream|teal}-{plain|marshmallow|cocoa|cinnamon}-{day|night}`。同一动作不绑定固定杯色/配料。

握持定位公式：人物左上角=`脚点-(16,29)`；杯图左上角=`人物左上角+hand-grip`。`grip`已经对应`flipX`后的像素。若用中心原点绘制杯图，其中心=`杯图左上角+(6,6)`，再按`flipX`翻转。这样不会因引擎翻转origin处理而漂移握点。

普通持杯绘制：body → hands → 杯 → 握点前方指尖。最后指尖可从hands层裁出`hand+(-1,0)`处2×2像素，保持原人物图位置；元数据提供该矩形。杯柄朝手，侧身杯身朝前，不把杯子缩放到不同大小。

递杯示意脚点相距28px，左右分别朝right/left；接杯帧没有杯。确认接受之前，杯对象留在原持有人；确认之后把**同一个杯ID**绑定到接收者hold动作。取消或离开如何恢复由业务状态决定，动画播完不能决定归属或复制杯子。

碰杯建议脚点相距24px，左右各偏中心12px，使用clink第1帧时杯沿接触。微光放在两人中点相对`(0,-13)`，约300ms；只是视觉反馈。碰杯仍须两位真实在场、各自持有杯子的状态确认，不能从图像或按键自行推定成功。

## 昼夜与减少动态

静态道具提供`-day/-night`两版，夜色已烘焙，避免再套同一份tint。人物身体/手臂为中性原色，按现有角色的共同环境光处理；不能只有新动作被额外缩暗或缩放。夜间预览用于配色依据，不声称已验证实际shader或设备色彩。

每组动画明确提供`reducedMotionAction`。控温/搅拌取第1帧；递杯/接杯取末帧；碰杯取第1帧直接表现接触，不做摇晃。蒸汽使用`steam-1-{day|night}`静帧，固定opacity 0.8、不透明度闪烁；碰杯微光在减少动态时省略，UI仍可给出确认反馈。

## 接入后的直接验收

检查锅口与勺尖、旋钮与手、台面遮挡、工位可达、退出落脚与旧沙发/门通路；两位身份都要检查。分别确认奶油/青绿与三种配料、四向持杯、递出取消/接受、碰杯、暂停/恢复/减少动态。真实成员、阶段、杯归属与结果唯一性都来自服务端；本包静态图不代替联机验收。
