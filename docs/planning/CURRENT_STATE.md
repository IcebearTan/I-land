## 对新阶段的影响

| 现有事实 | 新阶段处理 |
| --- | --- |
| `game.ts` 注册 Boot/Audio/Login/Island；AudioScene 集中播放，其余场景只发上下文 | SCENE-01 增加场景导航与生命周期，未来场景接 AUDIO_CONTEXT，不另建循环播放器 |
| `GAME_READY` 让 App 在登录场景启动后自动上岛，DOM 摇杆未区分场景 | 新增 SCENE_READY/SCENE_CHANGED；海边换动作工具条，室内保留漫步 |
| IslandScene 从浏览器本地时间算 tint，`phase` URL 参数仅本地预览 | 海边独立共享视觉时钟与时区；调整 tick 只影响景色，真实日期不受影响 |
| `/presence` 返回最近 visit，没有房间成员或姿势 | ROOM-01 增加带鉴权、失联清理、租约/版本的真实房间；不能直接拿 visits 画在线同伴 |
| User.id 与内部 name 不因改名而改变 | 房间、个人声音设置按稳定身份关联，不按可变登录名分配座位 |
| 现有依赖有 Phaser Sound Manager、FastAPI、uvicorn[standard]，Docker 未指定多个 worker | 声音和小范围实时共处可沿用现有栈；内存房间首版限制单 worker，实际部署必须核实 |
| UserPreference 与 GET/PUT /api/settings/audio 已实现 | 后续沿用稳定 user_id 和个人设置；仅更新指定字段，禁止改名后换一套偏好 |
| 旧信/日历面板已经通过 EventBus 打开 | 小屋家具接现有面板，避免把内容模块重做一遍 |
| M2 和恢复工具仍有已知缺口 | M2 留后续；坏备份拒绝恢复等数据保护在新版本发布前收口，不阻塞本地声音/场景设计 |
