四个可独立使用的里程碑：

1. 阶段 0–2：一个好看的、能一起待的家。
2. 阶段 3–4：能一起玩、一起留下作品和合照。
3. 阶段 5–6：不同时间来也能收到对方的回应。
4. 阶段 7–10：一座可以一起探索和建设的小岛。

阶段 10 完成并通过验收后，七个核心方向已有完整首版；阶段 11 是可长期逐批增加的内容。无需等全部实现才能使用。

## 2. 阶段任务

所有勾选均表示对应完成标志已有证据。草图、代码实现、本地检查、真机验收和上线分别记录。

### 阶段 0 · 接住现在的成果

- [x] **BASE-01 客厅收尾**：核对未提交 HOME-01，走通登录→进屋→坐下→电视/壁炉→回岛，补实际评估、截图与未测项，整理独立提交。只收尾已有成果，不重写客厅。
- [x] **BASE-02 保存与恢复保障**：沿用原 OPS-01，修复 restore 对 integrity_check 的结果判定，用临时库验证坏备份拒绝和独立恢复。失败不能覆盖现有真实数据。
- [ ] **BASE-03 回归入口**：整理两位身份、设置/静音、重连、桌面/手机、旧信/记忆的检查清单，记录可复现步骤与目前未测事项。

完成标志：当前功能可作为下一包的本地基线。BASE-02 是新版本发布前置，不阻塞独立绘画；完整真机与线上验收持续按 EXP-QA 跟进。

### 阶段 1 · 统一像素美术

本轮追加 UI/字号与比例整改，执行边界见 [第二轮安排](VISUAL_ROUND_02.md)。ART-01 完成仅代表静态样板交付，运行时接入与最新比例整改继续实施。

- [ ] **UI-01 全站样式与字号**：统一登录/HUD/设置/信箱/日历/海边/客厅的字体层级、面板、按钮、焦点与触控区域；主要中文和表单保持可读，按实际屏幕像素与场景文字共同验收。

- [x] **ART-01 壁炉旁样板**：确定木/布/石材质、家具厚度、局部暖光与生活细节，交付同一构图日/夜对照和简短风格表。
- [ ] **ART-02 两位角色统一规格**：对照现有 16px 版与候选更高画布，锁定比例、家具尺度、像素密度；制作四方向待机/行走和坐姿，脚底碰撞与画布分开。
- [ ] **ART-03 客厅正式资产**：精修壁炉、沙发、电视、窗、地毯，接图集/Tiled 遮挡层、碰撞与互动锚点；在真实游戏中验证样板。
- [ ] **ART-04 灯光与操作提示**：日夜、炉火/电视动画、靠近提示、入场文案与小屏构图统一，减少动态下仍有完整反馈。

完成标志：材质和体积可辨，角色跨场景比例一致，手机可读，提示不挡人物/炉火；实际进出与碰撞正确。新场景以后都按这套标准制作。

### 阶段 2 · 真正一起待在家里

- [ ] **ROOM-02 多场景房间基础**：扩展写死 seaside 的边界，定义独立小屋房间与跨场景接管规则，保留既有海边行为。旧请求不得清除新租约。
- [ ] **HOME-02 双人沙发与电视**：真实双方先后加入、空位分配、坐姿、共同频道/开关/节目进度；共享设置走 REST，个人音量独立。
- [ ] **SOCIAL-01 邀约与回应**：挥手、“来家里坐坐”“一起看海”、接受/忽略/取消；离线邀约下次可看，不自动移动对方。

完成标志：两个独立会话可共同休息、看电视，离开/断线不会留下假同伴。自由走动同步留到阶段 7。

### 阶段 3 · 第一杯热可可

首版范围：一个料理台、一种基础饮品、三种配料、两种杯型；基础食材直接供应。

- [ ] **PLAY-01 合作规则原型**：两个工位的控温与搅拌互相影响，可交换角色、暂停，一人可依次操作。实际试玩能解释两人为何需要配合；本地模拟明确标为原型。
- [ ] **PLAY-02 联机制作过程**：准备→制作→分杯→完成，阶段经 API 保存、重连恢复；错过温区可继续调整，失联不报废作品。
- [ ] **ITEM-01 作品与配方**：保存两杯成品、配料、配方名、真实参与者和实际日期，结果幂等；重复请求不复制成果。
- [ ] **SOCIAL-02 拿杯、递杯、碰杯**：专门动作帧、接杯回应、取消和离开恢复；双方状态一致，杯子交接不丢失、不复制。

完成标志：两人的操作有实际相互影响，可以完整玩完；刷新仍能查看真实成果。开始建立最少的作品数据，不提前搭复杂通用任务引擎。

### 阶段 4 · 留下共同经历

- [ ] **MEMORY-01 双人拍立得**：海边/客厅取景、姿势、倒计时、无 HUD 成图、重拍/放弃/保存。Phaser 经 EventBus 提供结果，React 走附件 API；参与者来自真实房间状态。
- [ ] **MEMORY-02 两人落款与活动纪念**：一条共同记忆关联活动/照片，两人分别续写自己的段落，进入原有日历；同时编辑不覆盖，重复保存不生成重复卡片。
- [ ] **HOME-03 六处陈列位**：壁炉台、墙面、窗边、门口可放杯子/照片/花瓶，查看来源、替换和撤回；更换摆件不删除原作品或记忆。

完成标志：游玩→作品→记忆→家中陈列已经连起来。实际日期和可调景色时间、游戏照片和现实照片来源清楚；普通移动/表情不自动写满日历。

### 阶段 5 · 花园与小礼物

- [ ] **GARDEN-01 四块花圃**：三种花、种植/成长/成熟/采收，按服务端现实时间计算；成熟等待，离线不枯萎，改设备时间或同时采收不能复制结果。
- [ ] **GARDEN-02 花色与搭配发现**：有线索的少量邻接配方、图鉴和新颜色，玩家能主动试验并理解变化。
- [ ] **GIFT-01 赠送与附言**：送花、离线待领取、收花、附言、插入花瓶，与来源记录关联；送出/领取原子完成。

完成标志：不同时间登录也能继续对方留下的花坛，送出和收到有来历的礼物。依赖 ITEM-01、MEMORY-02、HOME-03。

### 阶段 6 · 写给对方与未来

- [ ] **MAIL-01 双向信箱**：按原 NEXT_STAGE_M2 实现扫描件寄信/回信、可靠未读和软删除恢复，再加入短文字便笺；新增文字输入实施前补齐原 M2 契约，保持旧信兼容。
- [ ] **BOTTLE-01 漂流瓶**：短留言、打开、回应、收藏、海边瓶子反馈，有真实内容、归属和回看入口。
- [ ] **VOICE-01 语音留言**：录制/试听/重录/发送、文件/时长限制、上传重试、登录保护播放，桌面/实际移动权限与播放分别验证。属于留言，不是实时通话。
- [ ] **CAPSULE-01 时光胶囊**：信/照片/语音组成胶囊，设开放日期，服务端控制正文与附件访问；设备改时不能提前读，错过当天仍可打开。
- [ ] **RECALL-01 往年回看**：去年今日、活动/日期/来源检索、双方落款回看；无历史时不伪造纪念。

完成标志：从寄出到对方收到、回应，再到以后回看均可走通。前置为阶段 4，可与阶段 5、7 交换顺序。

### 阶段 7 · 一起走在岛上

- [ ] **MOVE-01 室内同行**：位置/朝向/动作同步、插值、地图/速度校验、断线重连；实际两人自由走动，离开即清理。
- [ ] **MOVE-02 主岛同行与交接**：主岛位置同步、分别进出房间、所在场景反馈；不同场景不会画出错误同伴，visits 不冒充在线。
- [ ] **SOCIAL-03 跟随、牵手、拥抱**：邀请/接受、随时解除、坐下/切场景的动作转换，边界与掉线能退出动作，不强迫拖动对方。
- [ ] **ART-05 主岛与海边美术迁移**：按既定标准精修建筑、植被、地面/岸线、人物和前景小物，进入正式地图/图集；海天保留留白，旧交互不退步。

完成标志：两人可以实际一起散步，画面与已精修客厅协调。依赖 ROOM-02 与角色规范，可在阶段 4 后优先做。

### 阶段 8 · 潮汐洞穴第一章

- [ ] **QUEST-01 谜题与灰盒**：两份互补线索、可说明的解法、可交换工具，先试玩规则，确保双方需要交流且有提示可继续。
- [ ] **QUEST-02 可玩洞穴**：浅滩/洞穴地图、符号关卡、水闸/浮木协作、检查点，误操作可重试，重连可继续；一人可依次使用工具。
- [ ] **QUEST-03 宝物与手账**：共同选择纪念物、地图印章、真实参与记录，宝物能摆进家中；奖励只发一次，重玩仍可探索。

完成标志：从入口到终点的一章短篇可完整合作游玩并留下成果。依赖阶段 7 与记录/作品基础；现实潮汐不会造成永久错过。

### 阶段 9 · 共建家园

- [ ] **BUILD-01 自由家具布局**：拖放、网格吸附、具有对应资产的方向旋转、撤销/恢复、并发保护；保存后出口、坐席、互动点可达，不能把另一人封在家具里。
- [ ] **BUILD-02 厨房与温室**：厨房承接料理、温室承接花园；先完成一个空间再做另一个，复用库存/成长规则和场景同步。
- [ ] **CRAFT-01 工作间与共同制作**：一人选图案/配色，一人打磨/装配，可换工，做风铃或木牌；作品可赠送/布置，有双方选择和来源。
- [ ] **BUILD-03 庭院与收藏系列**：花坛、路面小物、灯和探险收藏逐步改变岛的样子，替换不销毁历史记忆。

完成标志：空间变化可保存、可共同决定、可恢复；每个新增房间都有实际用途。依赖花园、探险及固定陈列。

### 阶段 10 · 天气与小仪式

- [ ] **EVENT-01 共同星图**：轮流选点、连线、命名、保存星图；可重访和修改副本，不覆盖原记忆。固定座位版本可在阶段 4 后提前做。
- [ ] **WEATHER-01 雨夜与共伞**：雨景、室内雨声、伞下站位/跟随、遮挡与减少动态；个人静音不被切换解除，小屏表现验证。
- [ ] **EVENT-02 水灯与漂流小事件**：写一句话、选灯、一起放下、回看，有真实保存结果并可手动重访。
- [ ] **EVENT-03 纪念日布置**：读取现有纪念日，选择桌布/灯饰/小节目，留下合照或留言；不要求准时登录，实际日期清楚。

完成标志：事件有一起发现/决定/留下纪念的完整过程。共伞依赖位置同步，节庆布置复用家园，不新增登录惩罚。

### 阶段 11 · 内容成长与持续精修

- [ ] **CONTENT-01 更多料理**：分别追加饼干、饭团、野餐盒，每种有不同步骤与分工，沿用作品和记忆出口。
- [ ] **CONTENT-02 花与装饰系列**：新花种、配方线索、杯型、相纸、风铃与家具系列，遵循美术规范。
- [ ] **CONTENT-03 探险后续**：新章节、工具与支线；先验证新机制再扩地图。
- [ ] **POLISH-01 持续改善**：按真实试玩反馈修动画、提示、声音、加载、触控、帧率与回看效率；每个问题有复现和验收记录。

各内容包彼此独立，前置是对应玩法首版稳定，可以按兴趣穿插。

## 3. 可调整的顺序

- 必须保持：真实房间→双人动作；合作活动→对应成果；稳定来源记录→陈列回看；位置同步→牵手/共伞/走动解谜。
- 阶段 5、6、7 可在各自前置完成后交换。特别想同行，就在阶段 4 后先做阶段 7。
- 杯型、相纸、动作草图、花种、洞穴纸面谜题、观星创意可随时提前设计；它们不会因此被标成已联机或已保存的功能。
- 真实视频共同播放、实时语音通话、多人社交和经济数值系统另立专题，不属于本次七类体验的主计划。

## 4. 每包的完成要求

| 类别 | 需要留下的结果 |
| --- | --- |
| 视觉 | 原始像素预览、关键姿势/材质、日夜/小屏，遵循 ART-01/02；资源来源可追溯 |
| 联机 | 独立身份双会话，加入/离开、掉线/重连、同时操作和迟到请求验证；不使用假同伴 |
| 持久化 | REST、稳定身份、原子并发/幂等与输入校验；刷新恢复，不使用 localStorage 存档 |
| 体验 | 一人可独立操作或保留进度；双人有实际配合；不登录不惩罚；静音和减少动态生效 |
| 检查 | 改前端做必要类型检查/构建，改后端只跑相关 pytest 文件/用例，按风险补有意义的测试，不跑全量回归；真实记忆不作试验 |
| 发布 | 实现/上线分开；沿用 EXP-QA 的备份恢复、HTTPS/WSS、单 worker 与回退条件，真机未测继续记录 |

一次整合一个任务包；完成后更新 CURRENT_STATE、任务项和评估并独立提交。临时缺少真机/线上条件时，继续可独立完成的本地设计和开发，不把未测项目勾选为通过。
