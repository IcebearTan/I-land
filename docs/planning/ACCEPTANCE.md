## 前端与两账号旅程

1. [ ] 小熊登录，写测试信，选择多张图、调整顺序、预览并寄出；确认按钮不重复提交。
2. [ ] 她在另一浏览器会话登录，看到未读；封面预览不变已读，拆信且首张正文加载成功后更新。
3. [ ] 网络图片加载失败时不标已读；重试成功后计数准确。
4. [ ] 她逐页阅读后回信，小熊收到；刷新、退出重登与切回前台状态保持一致。
5. [ ] 作者预览自己的来信记录不影响对方已读；收件人不能删除对方信件。
6. [ ] 作者删除/恢复自己的信；双方普通列表、回收站与未读数正确，附件仍在。
7. [ ] 模拟上传失败、保存响应丢失和超时；同一草稿重试不重复，顺序/文本仍在。
8. [ ] 同账号会话过期后重新登录，当前页面草稿可继续；显式换账号后旧草稿清除。
9. [ ] 未保存关闭/返回有确认，保存成功无多余确认；上传取消与组件关闭清理资源。
10. [ ] 场景启动晚于 API 返回、场景重入、退出再进岛和网络恢复均显示真实未读，不叠加计时器。

## 手机与回归

- [ ] 375/390px 浏览器视口：单列表单、长标题、多页图片、滚动与按钮不溢出。
