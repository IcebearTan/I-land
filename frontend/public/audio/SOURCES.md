## 夜间虫鸣的第三方来源

- 原作：[AMBIENCE NIGHT FIELD CRICKET 01.wav](https://freesound.org/people/sengjinn/sounds/175020/)，作者 **sengjinn**，2013-01-21 发布；作者描述为午夜蟋蟀的野外录音。
- 许可：[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)，允许修改和再分发；保留作者与作品链接作为来源记录。
- 2026-10-01 从作品页面公开的高质量 MP3 预览获取。原始 WAV 下载需登录，本次没有使用。
- 源文件入库于 `tools/audio_sources/night-field-cricket-175020.mp3`；完整下载地址、校验和见 [来源记录](../../../tools/audio_sources/README.md)。
- `tools/prepare_insects.py` 将实录转为单声道 22050 Hz，温和去除低频风噪及过亮高频，裁切成 58 秒，做 1.5 秒余弦交叉融合，并将循环起点移到近零的相邻采样；峰值限制为 0.22。没有改变实录节奏、插入周期静音或叠加合成蜂鸣。
- 先前的 `crickets.wav` 合成虫鸣已因用户反馈“像消息提示音”移除。新的文件名避免浏览器继续使用旧虫鸣缓存。

## 室内炉火的第三方来源

- 原作：[crackling_fire_021012.wav](https://freesound.org/people/moxobna/sounds/145774/)，作者 **moxobna**，2012-02-10 发布；作者明确描述为木柴在壁炉燃烧的立体声实录，带有 field / recording 标签。原作 182.776 秒，44100 Hz、立体声、PCM 16-bit WAV。
- 2026-10-02 核查作品页面明确标注 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)，允许修改及再分发，包含商业用途。派生的 `fireplace.wav` 保留 CC0；记录作者不表示其认可本项目。
- 原始 WAV 下载需登录，本次取作品页面公开的[高质量 MP3 预览](https://cdn.freesound.org/previews/145/145774_43834-hq.mp3)，共 4,764,864 bytes；SHA-256：`cff6136ac4ccebe04fa1cad2b253c9a854f001293ce75699c9ed4562718a0a00`。下载的源文件仅用于本地转换，部署仅包含处理后的 WAV。
- 离线解码使用 macOS 自带 `afconvert -f WAVE -d LEI16@22050 -c 1`，转为单声道 22050 Hz / PCM 16-bit。以下处理用 Python 标准库 `wave`、`array`、`math` 完成，不依赖运行时服务或新的播放器。
- 处理顺序：70 Hz 一阶高通去除轰声；以 `0.02 * tanh(sample / 0.02)` 软化短促木柴爆裂峰值；两级 3800 Hz 一阶低通柔化高频。保留真实燃烧声的自然时序，不叠加合成提示音或重新排列爆裂声。
- 从源录音 50 秒处取 32 秒，再用尾端后的 1.5 秒实录与循环头部做余弦交叉融合（权重 `0.5 - 0.5 * cos(pi * i / (overlap - 1))`）。整体旋转到第 113478 个采样的近零连续位置，峰值缩放至 0.18，最后量化为 PCM 16-bit。没有在循环边界插入静音。
- 成品 1,411,244 bytes，RMS 0.02616，首尾相邻采样差为 0.000122；SHA-256：`7927aebbe61012aa71361cfdb1d74067a46af2f7120d99ee82f59eed8d9b44a5`。自动检查覆盖时长、格式、音量上限、非静音与循环接缝；技术检查不能替代人耳听感，实际扬声器及手机试听仍需用户验收。

## 加载与混音

六条共约 10.58 MB（10.09 MiB）。登录页仅异步加载两条音乐（约 4.23 MB），登岛后再加载户外环境声，炉火仅首次进入小屋时加载；不阻塞场景和登录。
默认开启，浏览器拒绝自动播放时在首次点击或输入的同步调用链内恢复，设置中保留继续播放入口。
选择 PCM WAV 保留精确循环边界，避免有损编码填充引起的间隙；使用浏览器 Web Audio 解码，
不要求服务器安装音频工具或在运行时生成。浏览器无 Web Audio 时沿用 Phaser 的 HTML5 Audio 后备。
实际 iOS / Android 设备的听感、解锁及锁屏恢复仍需真机验收。

制作时对旋律做带限和软包络，延迟尾音绕回起点；鸟鸣/海浪底声在边界交叉融合；虫鸣为实录循环。
文件峰值（日曲 / 夜曲 / 鸟鸣 / 虫鸣 / 海浪 / 炉火）分别限制为 0.55 / 0.42 / 0.32 / 0.22 / 0.55 / 0.18。
两条音乐同帧启动，在零音量时也维持相同节拍位置；等功率分配音量，约 6–8 秒完成交接。
环境声约 3–5 秒平滑混音，夜间主岛鸟鸣权重为零，虫鸣替代；海浪根据海岸距离变化。
夜色权重跟随现实时间连续变化，预览 phase 参数只用于本地检查。音频播放速度固定 1×。
海边降低音乐并突出海浪；小屋使用同一音乐的现实昼夜编配，将户外鸟鸣、虫鸣及海浪平滑收住，音乐降为主岛内陆的 0.65 倍，炉火以个人环境音量的 0.42 倍轻轻进入。出屋后炉火淡出再暂停，再次入屋复用同一循环；电视和拨火不会改变音量设置或解除手动静音。隐藏暂停、手动授权及登录退出继续由唯一常驻 AudioScene 管理。

重新生成：在仓库根目录运行 `python3 tools/generate_audio.py`（四条原创声音，仅标准库），
然后运行 `python3 tools/prepare_insects.py`（实录虫鸣，标准库处理；离线解码使用 macOS 自带 afconvert 或已有 ffmpeg）。
服务器无需音频工具；播放使用随项目部署的 WAV，不请求第三方服务。
脚本打印时长、峰值、RMS 与首尾相邻采样差。技术指标不能替代听感，最终以实际试听反馈为准。
