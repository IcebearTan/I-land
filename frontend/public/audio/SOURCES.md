## 夜间虫鸣的第三方来源

- 原作：[AMBIENCE NIGHT FIELD CRICKET 01.wav](https://freesound.org/people/sengjinn/sounds/175020/)，作者 **sengjinn**，2013-01-21 发布；作者描述为午夜蟋蟀的野外录音。
- 许可：[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)，允许修改和再分发；保留作者与作品链接作为来源记录。
- 2026-10-01 从作品页面公开的高质量 MP3 预览获取。原始 WAV 下载需登录，本次没有使用。
- 源文件入库于 `tools/audio_sources/night-field-cricket-175020.mp3`；完整下载地址、校验和见 [来源记录](../../../tools/audio_sources/README.md)。
- `tools/prepare_insects.py` 将实录转为单声道 22050 Hz，温和去除低频风噪及过亮高频，裁切成 58 秒，做 1.5 秒余弦交叉融合，并将循环起点移到近零的相邻采样；峰值限制为 0.22。没有改变实录节奏、插入周期静音或叠加合成蜂鸣。
- 先前的 `crickets.wav` 合成虫鸣已因用户反馈“像消息提示音”移除。新的文件名避免浏览器继续使用旧虫鸣缓存。

## 加载与混音

五条共约 9.17 MB（8.75 MiB）。登录页仅异步加载两条音乐（约 4.23 MB），登岛后再加载环境声；不阻塞场景和登录。
默认开启，浏览器拒绝自动播放时在首次点击或输入的同步调用链内恢复，设置中保留继续播放入口。
选择 PCM WAV 保留精确循环边界，避免有损编码填充引起的间隙；使用浏览器 Web Audio 解码，
不要求服务器安装音频工具或在运行时生成。浏览器无 Web Audio 时沿用 Phaser 的 HTML5 Audio 后备。
实际 iOS / Android 设备的听感、解锁及锁屏恢复仍需真机验收。

制作时对旋律做带限和软包络，延迟尾音绕回起点；鸟鸣/海浪底声在边界交叉融合；虫鸣为实录循环。
文件峰值（日曲 / 夜曲 / 鸟鸣 / 虫鸣 / 海浪）分别限制为 0.55 / 0.42 / 0.32 / 0.22 / 0.55。
两条音乐同帧启动，在零音量时也维持相同节拍位置；等功率分配音量，约 6–8 秒完成交接。
环境声约 3–5 秒平滑混音，夜间主岛鸟鸣权重为零，虫鸣替代；海浪根据海岸距离变化。
夜色权重跟随现实时间连续变化，预览 phase 参数只用于本地检查。音频播放速度固定 1×。
海边 / 室内的混音契约已预留，但独立场景尚未实现。

重新生成：在仓库根目录运行 `python3 tools/generate_audio.py`（四条原创声音，仅标准库），
然后运行 `python3 tools/prepare_insects.py`（实录虫鸣，标准库处理；离线解码使用 macOS 自带 afconvert 或已有 ffmpeg）。
服务器无需音频工具；播放使用随项目部署的 WAV，不请求第三方服务。
脚本打印时长、峰值、RMS 与首尾相邻采样差。技术指标不能替代听感，最终以实际试听反馈为准。
