# Sources

- Original native-grid artwork for I-land, authored in the Cocoa-03 editable Python source.
- Pixel drawing primitives and material palette read from the project's accepted ART-02 source; accepted art-v2.1.0 character PNGs are read as fixed head/body/foot references.
- Ice Bear and Luo Xiaohei clothing cues follow the user's existing character direction. No claim of ownership over pre-existing character designs is added.
- No external asset pack, downloaded art, generated raster concept, font binary or media file is included.
- Runtime PNGs use integer drawing and binary alpha. Resizing is confined to documentation previews via nearest neighbour.
- Showcase text uses an installed system font; Chinese text and demo room participants are not baked into runtime props.
