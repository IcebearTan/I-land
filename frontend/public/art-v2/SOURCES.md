# Asset provenance

- Original integer pixel drawing authored for I-land in ART-02; retained core colours and material vocabulary from the project's ART-01 source, committed as `25e1cd8`.
- Characters follow the user-requested Ice Bear and black-haired islander wearing a teal Luo Xiaohei T-shirt and black trousers. This statement describes visual references; it does not claim ownership of those pre-existing character designs or grant a new licence for them.
- No third-party asset pack, downloaded game sprite, font binary, or stock image is included.
- The ART-01 ImageGen concept image remains a design reference only. None of its raster pixels were cropped, scaled or copied into these runtime assets.
- All PNGs are generated from editable native-grid source in `docs/planning/designs/art-02/source/`; no resampling is used to manufacture runtime frames. Nearest-neighbour enlargements are confined to previews outside this directory.
- Chinese text exists only on evaluation boards, using an installed system font; no UI text is baked into runtime images.
